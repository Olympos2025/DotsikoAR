# DotsikoARApp

This project uses ARKit and UIKit to display polygons/lines from a KML file in AR.    

**Instructions:**  
1. Open `DotsikoARApp.xcodeproj` in Xcode.  
2. Update bundle identifier & signing in `General` tab.  
3. Build on an ARKit-capable iOS device.  
4. Tap 'Open KML' button (to be implemented) to select your own KML file at runtime.  
5. The app will render the KML overlays in AR.

Upload this folder's contents directly to GitHub for cloud building (Codemagic/Appcircle).
